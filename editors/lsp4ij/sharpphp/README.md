# SharpPHP language server for PhpStorm

An [LSP4IJ](https://plugins.jetbrains.com/plugin/23257-lsp4ij) template: completion, errors while typing,
hover and go to definition for `.sphp` files in PhpStorm and other JetBrains IDEs. It starts
`php $PROJECT_DIR$/vendor/bin/sharp lsp` of the open project (SharpPHP 0.3 or newer).

1. **Settings → Plugins → Marketplace**: install **LSP4IJ** (restart PhpStorm if it asks).
2. **Settings → Languages & Frameworks → Language Servers (LSP4IJ)**, click **+**.
3. **Template** → **Import template...** → select this folder → **OK**.

The full guide, with highlighting, running programs and troubleshooting, is
[PhpStorm setup](../../../README.md#phpstorm-setup) in the README.
